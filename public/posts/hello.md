# 欢迎来到我的博客

## 关于这个项目

这个网站使用 Vue 3 + Vite 构建，具有以下特点：

- 🎨 主题切换（深色/浅色模式）
- 📝 Markdown 渲染
- 💻 代码高亮
- 📱 响应式设计

## 代码示例

这是一个简单的 JavaScript 函数：

```javascript
function greet(name) {
  console.log(`Hello, ${name}!`);
  return `Welcome to my blog, ${name}`;
}

greet('Visitor');
```

以及一段 Vue 组件代码：

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)
</script>

<template>
  <button @click="count++">
    Clicked {{ count }} times
  </button>
</template>
```
